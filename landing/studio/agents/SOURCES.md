# Agent logo sources

Locally hosted SVG assets retrieved on 2026-10-21. Logos identify their respective tools; they remain the property of their respective owners.

- `claude.svg`: Asterisk path from the [official Claude wordmark](https://claude.com/product/claude-code), with its original 125 × 125 coordinate space and Claude's terracotta color.
- `openai.svg`: OpenAI Blossom SVG from the [official Codex documentation](https://developers.openai.com/codex/). [Brand guidelines](https://openai.com/brand/).
- `opencode.svg`: [Official OpenCode favicon SVG](https://github.com/anomalyco/opencode/blob/dev/packages/ui/src/assets/favicon/favicon-v3.svg). [Brand assets](https://opencode.ai/brand).
- `antigravity.svg`: [Full-color icon SVG](https://www.antigravity.google/assets/image/brand/antigravity-icon__full-color.svg) from Google's [Antigravity press assets](https://www.antigravity.google/press).
- `pi.svg`: [Official Pi logo SVG](https://pi.dev/logo.svg) from the [Pi press kit](https://pi.dev/press-kit).
- `acp.svg`: [Official ACP logo SVG](https://agentclientprotocol.com/logo/light.svg) from the [Agent Client Protocol website](https://agentclientprotocol.com/).

Claude and Codex use Studio's native connections. Other agents use a compatible ACP command or adapter, as documented in the repository's desktop documentation. This list identifies connection options, not an endorsement or a claim that every agent/platform combination has been qualified.
