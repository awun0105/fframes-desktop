# Studio website palette

The approved blue Studio logo anchors both landing pages. Blue is the primary action and identity color; navy provides contrast, and the figures use softer supporting colors.

| Role                        | Color     |
| --------------------------- | --------- |
| Primary / cobalt            | `#2864F5` |
| Hover / royal blue          | `#174FD5` |
| Ink / midnight navy         | `#15294B` |
| Secondary text / slate blue | `#586B85` |
| Page / ice white            | `#FAFCFF` |
| Surface / powder blue       | `#EDF3FF` |
| Figure / lavender           | `#EEEAFF` |
| Figure / mint               | `#E5F4EF` |
| Figure / peach              | `#FFF0E3` |
| Selection / rose            | `#FBE7EF` |

Keep main actions blue. Use the pastel palette to distinguish diagram layers; use green checkmarks for successful validation.
