# Kit phase 23: cursors, animated emoji, sound effects and GIFs

Phase 23 is complete. A subagent built it in a worktree, and its commits were cherry-picked
onto main:

- 5 commits: the kit assets, the gallery scenes, the docs, the lock file, and the e2e
  snapshots (`test(kit): snapshot the cursor, click and GIF scenes`).
- **Conflict.** One conflict in `gallery/src/scenes/mod.rs` (the voiceover and assets
  scenes); both lines were kept.
- **Lock file.** The lock commit was staged from the branch's blob with
  `git update-index --cacheinfo`, which left the user's uncommitted `components/Cargo.lock`
  edits untouched. Before that, it was checked that HEAD's lock still equalled the branch
  base.

## Sound effects

The licences are in `components/fframes-kit/sfx/LICENSE.md`. Every page was checked
again for CC0 on 2026-10-25, when its file was downloaded. Each file was:

- trimmed to its sound (at most 1.9 s);
- converted to mono, 44.1 kHz and 16 bit;
- set to a peak of -3 dBFS;
- given a 20 ms fade at its end.

## Deviations from the plan

- **Gallery copies of the sounds.** The gallery's `media/` has copies of the seven WAVs.
  `include_media_dir!` embeds only its own folder, and the scenes play the files by name.
- **The gallery GIF.** `media/gif/bounce.gif` is a GIF drawn for the gallery (1,833 bytes,
  no third-party content).
  - It sits in a subfolder and is read with `include_bytes!`, because
    `include_media_dir!` panics on `.gif`.
  - The same constraint put the phase-22 caption files in `gallery/captions/`.
- **Scene audio.** `gallery/src/lib.rs` gained a `tracks` hook, so a gallery scene can
  carry several `AudioTrack`s (the SFX scenes) as well as one file.
- **`TransitionSfx`** demonstrates `sfx::on_transitions` over a `Fade` series.
- **The kit alone on wasm32.** The subagent found that building the kit alone for wasm32
  fails in `getrandom`, and judged it older than this phase. That was not checked again on
  main. `check-wasm` builds the gallery bridge, which passes.
- **`check-wasm` without `lottie`.** This is phase 22's clean run at 84889f1d, before the
  gallery enabled `lottie`. The run above covers the build with `lottie` and `gif`.
- **Scene audio after the merge.** Phase 22 and this phase both changed how gallery scenes
  carry audio. After the merge, `audio analyze Voiceover` measured -16.0 LUFS and a true
  peak of -6.2 dBTP, so the phase-22 scene still plays its file. `WordCaptions` has never
  had audio.
- **Named tests.** The tests the phase lists exist and pass:
  - `on_transitions_hits_each_overlap_start`, `on_beats_matches_the_beat_grid` and
    `on_clicks_follows_the_cursor`;
  - `cursor_path_reaches_each_point_at_its_time`;
  - `picks_the_frame_from_the_delays` and `loops_or_holds_the_last_frame`.
