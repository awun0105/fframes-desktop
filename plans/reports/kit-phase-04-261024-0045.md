# fframes-kit, text, overlays, general components and the studio intro migration

Date: 2026-10-24. Windows Server VM, CPU renderer (`--renderer cpu`), release build.

## Result

`fframes-kit` now has the high-reuse components of the overview map, in five slices:

- motion: `Beat` (beat grid), `timecode`, `thousands` and the example's easing curves;
- text: `FitText`, `Letters`, `TextReveal`, `Typewriter`, `Counter`, `Paragraph`, `HudLabel`;
- overlays: `Appear`, `LowerThird`, `Captions`, `CaptionStack`, `ChapterList`,
  `Annotation`, `ProgressBar`, `Check`;
- data, audio, decoration, media: `BarChart`, `SpectrumBars`, `Waveform`
  (`audio::spectrum`, `audio::wave_path`), `DrawOn`, `CornerMarks`, `Glow`, `DropShadow`,
  `PhotoFrame`, `KenBurns`.

Every component has a gallery scene, a row in `docs/components/components.md` and doctested
examples (20 doctests). The e2e harness renders 23 new key frames of them. The recipes for
a lower third (Overlays), a counter (Text) and draw-on (Data, audio, decoration and media)
are in those sections.

`examples/fframes-studio-intro` depends on the kit by path and draws its HUD with it. Its
key frames are pixel-identical to the frames before the migration.

## Studio intro migration

- Reference: `frame` at 30 times (1% to 96.7% in 3.3% steps) for each of the three binaries
  (`fframes-studio-intro`, `-portrait`, `-short`), before the kit dependency was added, and
  `inspect --json` of each.
- After: the same 90 frames compared with odiff at the e2e settings (threshold 0.15,
  antialiasing): **90 identical, 0 under the threshold, 0 above**. `inspect` checked the same
  frames (506, 452, 175) and reported the same findings as before (1, 4, 2, all present
  before the migration).
- `cargo tree -i fframes`: one `fframes` (the workspace path crate) under both
  `fframes-kit` and `fframes-components` 0.1.2. The root `Cargo.lock` gained the
  `fframes-kit` package and its edge only (9 added lines, nothing removed).
- `cargo fmt -p fframes-studio-intro -- --check` (read only): clean.
- `cargo clippy -p fframes-studio-intro -- -D warnings`: clean. With `--all-targets`, two
  `default_trait_access` errors come from `examples/career_day_*.rs` of that crate
  (commit `a1173f52`, before this work); not changed here.
- `src/scenes/keynote/speed.rs` still shows only the user's uncommitted rename
  (`fo, fd` to `po, pd`) and was not staged.

What moved where:

| Before | After |
| --- | --- |
| `beat.rs` grid math, easing curves, springs, `pulse` | `fframes_kit::motion` (`Beat`, `spring`, `expo_out`, ...); `beat.rs` is a facade on `Beat::new(BEAT, DOWNBEAT0)` |
| `ui.rs` `corners` | `CornerMarks { .. }.draw()` behind the same function |
| `ui.rs` `label` | `HudLabel { uppercase: false, .. }.draw()` behind the same function |
| `ui.rs` `timecode(seconds)` | `motion::timecode(frames, 60)` at its one call |
| `ui.rs` `callout`, `letters`, `thousands` | deleted: unused in the example (the kit has `Annotation`, `Letters`, `thousands`) |
| `ui.rs` palette, fonts, cached `measure`, `Slam` | `brand.rs` (renamed from `ui.rs`), example-specific |

## Bench

`components_gallery_bin --renderer cpu render <Scene>`, 150 frames at 1920x1080, wall time
including process start, two sets of five interleaved runs. `BenchKit` now also has a
`LowerThird` and a `Counter`. `BenchHandWritten` has the same lower third and counter
written in plain `svgr!` and `timeline!`.

| Pair | Hand-written (ms) | Kit (ms) | Median H (10 runs) | Median K (10 runs) |
| --- | --- | --- | --- | --- |
| `BenchHandWritten` / `BenchKit` | 396, 436, 421, 431, 460, 332, 524, 402, 391, 484 | 360, 430, 411, 631, 365, 418, 464, 565, 391, 669 | 426 | 424 |

The first set alone had the shape pair's kit side 12% slower and the second 8% faster.
Runs vary by about 20%. Over ten runs both pairs are within 1%, inside the 10% budget. The
bench card is no longer pixel-identical between the two halves: the hand-written lower
third uses `EaseInOut` where `LowerThird` uses the theme's enter easing.

## Deviations from the phase file

- **`beat.rs` kept as a facade.** The plan deletes it. Two things keep it:
  - `speed.rs` has uncommitted changes of the user and glob-imports `crate::beat::*`, so
    every name must stay.
  - The example's beat constants are its own.

  The math lives in the kit. Two functions keep their example bodies:
  - `prog`: kit `progress` steps on a reversed window, where `prog` ramps down. 109 calls
    have non-literal windows, so `prog` cannot be proven equal to `progress` for them.
  - `hash`: sin-based, which the kit's integer hash does not reproduce.
- **`Beat` stores `period`, not `bpm`.** The example's period (0.454522 s) is measured;
  `Beat::from_bpm` exists for round tempos.
- **`ui.rs` renamed to `brand.rs`, not deleted.** The palette, the `measure` helper and
  the `Slam` brand title are example-specific. `measure` caches widths across frames and
  estimates them from the character count without a font; the kit's `Ui::measure` (which
  takes a `FontQuery`, italic included) does neither. The plan allowed that ("whatever
  stays example-specific moves into that example's files").
- **Scope note: easing curves in `motion`.** `expo_out`, `expo_in`, `cubic_in_out` and
  `quart_out` were added to `motion` beyond the listed beat grid and `timecode`, because the
  example's `beat.rs` exports them and the facade re-exports the kit's copies.
- **`draw()` without `Ui`** on `HudLabel` and `CornerMarks`, like `Annotation::draw`: the
  example's helpers only have a `Frame`. Thin adapters keep the example's call sites
  unchanged (about 30 calls), so the rendered SVG stays the same.
- **The overlay callout is `Annotation`.** `Callout` is the Remotion speech bubble from
  the shapes.
- **`Counter` has no tabular figures** (fframes text has no OpenType feature switch). It
  is right aligned by default instead, so the digits stay in place.
- **`Captions` has no glow prop.** It composes with the `Glow` filter.
- **`text` props are `Cow<str>`**, so frame-built strings need no leak.
- **`key`** exists only where the component emits an id (`PhotoFrame`, `KenBurns`), as in
  phases 2 and 3. `Glow` and `DropShadow` take the `id` itself.
- **Gallery media is generated** by `components/scripts/gallery-media.mjs`: a 3 s tone file
  (130 KB) and a 2.5 KB photo. Gallery scenes can now play audio (`with_audio`).
