# Kit phase 5: LaTeX formulas, measurements

Status: in progress (first slice: install, pipeline, parts marking, engine, `Formula`).

## TeX installation on the VM

- `choco install miktex -y` failed: the Chocolatey server timed out (the package is also
  flagged "possibly broken").
- I used MiKTeX's own command-line installer, `miktexsetup_standalone.exe` (MiKTeX Setup 5.5).
  - A `--remote-package-repository` URL straight from mirror.ctan.org failed ("remote package
    repository is not registered").
  - The registered MIT mirror worked:
    `--remote-package-repository=https://mirrors.mit.edu/CTAN/systems/win32/miktex/tm/packages/`
    with `--package-set=basic download` into a local repository (251 MB).
  - Then `--local-package-repository=<repo> --package-set=basic --shared=no install`.
- Automatic package installation: `initexmf --set-config-value [MPM]AutoInstall=1`.
- Installed: MiKTeX 26.5, MiKTeX-pdfTeX 4.27, dvisvgm 3.6, xelatex and lualatex present, in
  `%LOCALAPPDATA%\Programs\MiKTeX\miktex\bin\x64` (found by discovery's default folder; `PATH`
  not needed).

## Pipeline proof (six samples)

Run: `latex -interaction=nonstopmode -halt-on-error`, then
`dvisvgm --no-fonts --exact-bbox`. The SVGs are checked in as
`components/fframes-kit/src/latex/samples/*.svg` and parsed by `dvisvgm_samples_parse_into_glyphs`.

| sample | latex | dvisvgm | SVG bytes |
| --- | ---: | ---: | ---: |
| `e^{i\pi} + 1 = 0` | 17446 ms (first run, installs packages) | 550 ms | 6100 |
| `\frac{a+b}{c}` | 540 ms | 465 ms | 4262 |
| 2x2 `pmatrix` | 594 ms | 403 ms | 6649 |
| `\sum_{k=1}^n k = \frac{n(n+1)}{2}` | 554 ms | 416 ms | 12844 |
| `\ce{2H2 + O2 -> 2H2O}` | 28257 ms (first run, installs mhchem, chemfig) | 476 ms | 5549 |
| TikZ arrow, circle, square | 862 ms | 464 ms | 1245 |

So a formula takes about 1 s to typeset once its packages are installed.

## Parts marking

- Chosen: dvisvgm raw specials around each `{{ }}` group,
  `{\special{dvisvgm:raw <g id='part-N'>}..\special{dvisvgm:raw </g>}}`.
  - It is a braced group, so a part is spaced like Manim's `{{..}}`.
  - `\part{name}{..}` writes `label-name` the same way.
  - The macros are defined right after `\begin{document}`, so they work with any preamble.
- The groups survive dvisvgm with exactly the glyphs of each part, in all four cases below
  (`part_markers_survive_as_groups`).
- The positions are **not bit-identical**. A marker pair moves the glyphs after it by up to
  one scaled point (1 sp = 1/65536 pt = 1.53e-5 pt). That is TeX's unit, and dvisvgm writes it
  in the fifth decimal. At 4.8 px per pt it is 1.2e-4 px, which no render can show. I
  accepted it with a 2 sp tolerance (`part_markers_keep_glyph_positions`, on checked-in plain
  and marked SVGs).

| case | max abs dx | max abs dy |
| --- | --- | --- |
| `{{a}}^2` | 1.3e-5 pt (0.85 sp) | 0 |
| `\frac{{{a}}}{b}` | 0 | 0 |
| `\left({{x}}\right)` | 1.3e-5 pt (0.85 sp) | 0 |
| `{{a}} + {{b}} = {{c}}` | 2.5e-5 pt (1.6 sp) | 0 |

## Engine round trip

`typesets_with_the_installed_tex_and_caches` runs only when TeX is found (otherwise it
prints "skipped"). It checks that:

- typesetting `{{a}}^2 + \part{rest}{b}` writes one cache file;
- the part and label ids come through;
- an engine without tools reads the same formula from the cache;
- an uncached formula without tools gives `NotInstalled`;
- `\undefinedmacro` gives `Compile`, with the log excerpt starting at
  `! Undefined control sequence`.

It takes 1.6 s, with TeX.
