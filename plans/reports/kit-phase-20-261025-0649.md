# Kit chemistry II: decisions and measurements

Measured 2026-10-25 on the CPU-only VM: 32 logical processors, Windows Server 2022.

## `.mol` support

`chematic` 1.2.1 reads MOL and SDF only behind its `mol` feature, through `chematic-mol`. That
crate reads about 40 formats. It also brings six more `chematic` crates, `flate2`, `roxmltree`
and `serde_json` into the editor's wasm. No smaller crate on crates.io reads V2000 files and
also builds on `chematic`.

`MolFile` is therefore a V2000 parser of its own. It reads:

- the atom and bond blocks in fixed columns;
- `M  CHG`, which replaces the charges of the atom block;
- the first record of an `.sdf` (it stops at `$$$$`).

V3000 files are rejected with `MolError::V3000`. Files without positions, and files with 3D
positions, are laid out by `chematic` through the same code as SMILES. 3D positions go to
`Molecule3D` unchanged. No dependency was added, and `components/Cargo.lock` did not change
during the phase.

## Electronegativity

`mendeleev` 0.8.4 is its latest release and has no electronegativity. `ElementCard` carries
the Pauling values of Wikipedia's electronegativity data page, checked against the page value
by value. Where the page lists several values the first is used (Fr 0.7). He, Ne, Ar, Rn and
the elements from Rf have no value; Pm, Eu and Yb have only a range there and get none. The
other card values come from `mendeleev`.

## Changes beside the new components

- `subscript_text` now takes a `Script` (base, sub, super) and a text style.
  - It draws each space as a gap between two `<text>` elements. A space inside a run was
    measured narrower than it was drawn, so the superscript after `[Ar] 3d` overlapped the
    `d`.
  - The Equilibrium and Orbital labels have no spaces; their snapshots did not change.
- Three docs headings that earlier kit commits had glued to their paragraphs were fixed:
  `## Shapes`, `## Circuit` and `## Collision1D`.
- The clippy matrix now also runs `--all-targets` with each feature set (`chemistry`,
  `chemistry,3d`, `studio,chemistry`, `physics`, `physics,3d`). The chemistry tests had not been
  linted before, and one test had a `use` after a statement.
